An end-to-end pipeline that turns invoice PDFs and scanned images into validated, queryable data.
Text is extracted natively (or via OCR for scans), an LLM extracts structured fields into a Pydantic
schema, a validation engine checks the data, records are routed by confidence, and everything is loaded

## Architecture

```
PDF / image -> ingest (PyMuPDF native text, Tesseract OCR fallback)
            -> LLM extraction (Claude + Instructor, output forced into a Pydantic schema)
            -> confidence score (LLM self-report + grounding in source text + OCR quality)
            -> validation (required fields, date logic, arithmetic, known vendors, currency, outlier detection)
            -> routing (auto_approved | review_fast | review_detailed)
            -> PostgreSQL (invoices, line_items, validation_results) -> SQL analytics
```

## Setup

1. Install Python 3.10+, Tesseract (`brew install tesseract`) and PostgreSQL; create a database called `invoices`.
2. `python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt`
3. `cp .env.example .env` and fill in your API key and database URL.
4. `python -m src.check_setup`

## Run

```
python -m src.generate_data     # create synthetic invoices + answer keys
python run_pipeline.py          # ingest -> extract -> validate -> route -> load to PostgreSQL
python -m src.evaluate          # accuracy report vs. ground truth
psql "$DATABASE_URL" -f src/queries.sql   # analytical SQL queries
pytest                          # unit tests for the validation rules
```
